## 4. 审查中发现并修复的问题

| 级别 | 问题 | 影响 | 修复与验证 |
| --- | --- | --- | --- |
| 高 | 字幕由工作台和宿主各自启动退场计时 | 宿主的短计时会抢先清掉仍应随真实音频时长显示的字幕 | 删除宿主重复计时，保留原字幕控制器为唯一时钟；Electron E2E 验证超过宿主事件时长后字幕仍显示 |
| 高 | 普通字幕退场使用全量清除 | 一条底部字幕结束时会同时删掉仍在飞行的战斗弹幕 | `caption-clear` 增加 `bottom/all` 作用域；底部退场只清字幕，禁用/重载才全清；E2E 验证弹幕保留 |
| 高 | 原生 `WebContentsView` 位于工作台 DOM 上方 | 拖动遮罩、命令面板、CG 灯箱、战果详情和崩溃面板可能被游戏画面挡住或吞鼠标 | 统一侦测遮挡元素，在嵌入模式临时隐藏原生视图；同时监听 `class` 和 `hidden` 变化 |
| 高 | 迁移失败时可能在没有真正挂回来源窗口的情况下报告稳定态 | 画面可能丢失，但状态仍显示“嵌入”或“独立” | 只有确认来源窗口、边界和重新挂载均成功才进入稳定态，否则进入 `RECOVERING` |
| 高 | guest 崩溃后在旧 guest 销毁前触发重建 | 有机会短暂存在两个 guest，破坏“同一会话、同一实例”的核心约束 | 先关闭并等待旧 guest 的 `destroyed`，再通知宿主重建；仅 guest 崩溃恢复可由新挂载清除恢复态 |
| 中 | 通知合并从 1 重新计数，且合并后仍跳到第一条详情 | 批量通知数量错误，点击目标与“已合并”语义不一致 | 传递原批次数量；合并后显示累计数量、最新正文，并改为模块总览动作 |
| 中 | 横幅动作固定 60 秒失效，锁定通知关闭后动作回调不释放 | 长时间保留的横幅按钮可能失效；频繁关闭锁定通知会积累回调 | 横幅 token 与横幅生命周期绑定；通知在关闭、超时、合并替换和溢出淘汰时经受限 IPC 同步释放 |
| 中 | 打包脚本从 `package.json` 兼容范围推导 Electron 版本 | 实际安装和测试为 `43.4.1`，打包却可能使用范围下界 `43.2.0` | 从 `package-lock.json` 读取精确版本；检测已校验的 Electron 缓存 ZIP，离线环境不再额外获取 SHASUMS |
| 低 | 拆出前专注模式按钮状态未可靠同步 | 独立窗口模式下按钮文字/禁用态可能与实际布局不一致 | 拆出前无条件退出专注模式；只有 `EMBEDDED` 稳定态允许进入专注模式 |
| 低 | 设置页窗口模式选项使用不可访问的 `span` | 键盘不可操作，忙碌态仅靠样式表达 | 改为带 `aria-pressed` 和原生 `disabled` 的 `button` |
| 低 | 启动遮罩层级低于游戏内容但高于部分字幕/通知关系不完整 | 启动动画期间可能露出游戏内容或压住重要通知 | 恢复原启动遮罩层级，并让横幅、通知和错误恢复层保持在其上方；补充 live region 原子性 |

字幕和弹幕容器的最终计算背景均为 `rgba(0, 0, 0, 0)`。用户反馈的字幕黑底已消除，且真实 Electron DOM 测试已固定该结果。

## 5. 兼容性与安全审查

### 窗口与会话

- 游戏 guest 只创建一次；嵌入与独立模式迁移的是同一个宿主视图。
- 迁移期间 guest `webContents.id`、renderer PID、session、宿主实例、guest 实例、iframe 实例和音频实例均保持不变。
- 独立窗口关闭会回收到工作台；目标窗口创建失败、目标挂载失败和独立窗口异常关闭均有明确回滚或恢复路径。
- 独立窗口位置会持久化；屏幕移除或分辨率变化时会重新限制到可见工作区。
- 工作台缩放只换算一次原生视图边界，游戏内容继续按 5:3 等比包含，不拉伸。

### 原功能兼容

- 字幕仍由原语音解析、季节占槽判定和真实音频时长控制。
- 战斗弹幕的友军/敌军方向、轨道和动画时长保持原逻辑。
- 演习继续按原产品约定抑制全部语音文字。
- 通知历史、声音、勿扰、锁定通知不自动消失、卡面点击仅关闭等原语义保留。
- 新舰/大破/修理/女神/婚礼横幅仍保留跳转、关闭、框体光效和婚礼花瓣联动。
- 独立模式只释放原游戏区域，左右坞与底坞原布局数据不被改写。

### IPC 与安全边界

- 工作台禁用 `webviewTag`，仅可信游戏宿主允许创建 webview。
- 主进程按注册的宿主和 guest `webContents.id` 校验消息来源。
- preload 只暴露固定操作，不暴露 `ipcRenderer` 或任意脚本执行入口。
- 覆盖层 DTO 对类型、长度、枚举、数量和时长做边界校验。
- 通知动作使用随机、一次性 token；关闭和替换会显式撤销，不接受脚本内容。
- 本轮没有新增网络请求或远端依赖。
